# 🩺 ME18: Tinea vs Candidiasis Classifier

GET 324 (Artificial Intelligence, Machine Learning and Convergent Technologies)
Mini-Project — Laboratory Exercise 10 — Mechanical Engineering Group **ME18**

A binary image classifier that predicts whether a photo of a skin lesion
shows **Tinea** (a fungal/ringworm-type infection) or **Candidiasis** (a
yeast/Candida infection), built with MobileNetV2 transfer learning and
deployed as a Streamlit web app.

## 📊 Dataset
**Skin Disease Dataset** (22 skin condition classes)
Source: Kaggle — https://www.kaggle.com/datasets/pacificrm/skindiseasedataset

Only the **Tinea** and **Candidiasis** classes were used from this dataset
(it contains 20 other skin condition categories not needed for this task).

## 🧠 Model
- **Architecture:** MobileNetV2 (ImageNet pretrained) + GlobalAveragePooling
  + Dropout + Dense(1, sigmoid)
- **Training strategy:** two-phase transfer learning
  1. Train new classification head with the MobileNetV2 base frozen
  2. Fine-tune the top layers of the base model at a low learning rate
- **Data augmentation:** random flip, rotation, zoom, contrast, brightness
  (applied only during training, to reduce overfitting)
- **Class balancing:** automatic class weighting to handle any imbalance
  between Tinea and Candidiasis image counts

## ▶️ How to Run Locally

1. **Clone this repository**
   ```
   git clone https://github.com/<your-username>/<your-repo>.git
   cd <your-repo>
   ```

2. **Create and activate a virtual environment** (recommended)
   ```
   python -m venv venv
   venv\Scripts\activate        # Windows
   source venv/bin/activate     # macOS/Linux
   ```

3. **Install dependencies**
   ```
   pip install -r requirements.txt
   ```

4. **(Only if retraining) Download the dataset** from the Kaggle link
   above, and place the two class folders inside `dataset/` exactly as:
   ```
   dataset/Tinea/
   dataset/Candidiasis/
   ```
   Then run:
   ```
   python prepare_data.py
   python model.py
   ```
   This regenerates `me18_skin_classifier.keras` and `class_names.json`.
   (Skip this step if you're just running the app with the already-trained
   model included in this repo.)

5. **Run the app**
   ```
   streamlit run app.py
   ```
   Your browser should open automatically at `http://localhost:8501`.
