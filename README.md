# GET324 - Tinea vs Candidiasis Skin Disease Classifier

## Project Overview

This project is a deep learning application developed as part of the GET324 Laboratory Exercise on Cloud Computing and AI Model Deployment for Engineering Applications.

The application uses a Transfer Learning model based on **MobileNetV3Small** to classify skin disease images into two categories:

- Tinea
- Candidiasis

The trained model is deployed through a Streamlit web application, allowing users to upload a skin image and receive an instant prediction.

---

## Dataset

The dataset used for this project consists of skin disease images obtained from Kaggle.

To ensure balanced training, the dataset contains:

- Tinea: 248 images
- Candidiasis: 248 images

Total images used: **496**

The images were resized to **224 × 224 pixels** before training.

---

## Model Architecture

The project uses a **Transfer Learning** approach.

Base model:
- MobileNetV3Small (TensorFlow/Keras)

Classification layer:
- Global Average Pooling
- Dropout
- Dense Output Layer with Sigmoid Activation

Loss Function:
- Binary Crossentropy

Optimizer:
- Adam

## How to Run the Application

1. Install the required packages:

```bash
pip install -r requirements.txt
```

2. Run the Streamlit application:

```bash
streamlit run app.py
```

3. Open the displayed local URL in your web browser.

4. Upload a skin image.

5. The application predicts whether the image is:

- Tinea
- Candidiasis

and displays the prediction confidence.
